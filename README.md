🤖 PROMPT-LAB — AI Chat Agent

PROMPT-LAB is an AI-powered chat agent built with Python and Streamlit. 
It allows users to enter prompts and receive AI-generated responses through a simple web interface.

 🚀 Features

- 💬 AI Chat Agent
- 🧠 Prompt-based interaction
- ⚡ Fast AI responses using Groq
- 🎨 Simple Streamlit user interface
- 🔐 API key support using environment variables/secrets
- 🐍 Built with Python

 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Git & GitHub
